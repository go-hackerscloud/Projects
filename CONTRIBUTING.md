# Contributing to GoHackersCloud Learning Hub

Thanks for helping make cybersecurity education more practical and accessible.

## Good contributions

- Correct a factual or technical error with a reproducible explanation.
- Add beginner-friendly documentation or diagrams.
- Add small, original examples meant for local or explicitly authorized lab use.
- Improve accessibility, links, language, and navigation.
- Propose learning resources or exercises that respect intellectual property.

## Contribution workflow

1. Open an issue explaining the proposed change and intended audience.
2. Work from a feature branch in your fork.
3. Keep changes focused and update relevant documentation.
4. Validate Markdown links, code examples, and safety boundaries.
5. Open a pull request explaining the changes and how they were tested.

## Content quality

Prefer: **Objective → Concept → Environment → Steps → Expected observation → Explanation → Cleanup**.

Use fenced code blocks with a language identifier. Provide expected results as examples, never as guaranteed results across all environments.

Do not submit secrets, internal infrastructure details, proprietary question banks, paid course copies, third-party copyrighted material without permission, or instructions targeting systems without authorization.

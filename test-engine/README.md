# GHC Test Engine — practice and assessment

Practice assessments help learners identify knowledge gaps and prepare for further study.

## Suggested practice workflow

1. Select the topic or certification domain you want to assess.
2. Complete a short sample assessment without looking up answers.
3. Review explanations, not just correct choices.
4. Revisit the relevant Foundation or Academy lesson.
5. Retest and track improvement.

## Public example questions

**Q1.** Which HTTP response status generally means a resource was not found?

A. 200 · B. 301 · C. 404 · D. 500

**Answer:** C (404). It indicates the requested resource could not be found.

**Q2.** What is the principle of least privilege?

A. Give all users admin rights · B. Grant only the permissions needed for the task · C. Disable logging · D. Share credentials

**Answer:** B. Minimize privileges to reduce the impact of mistakes or compromise.

These are original illustrative questions, **not** official certification exam questions.

Explore the [course catalog](https://www.gohackerscloud.org/courses) for current assessment and training offerings. A dedicated verified Test Engine URL has not been established here; do not treat this folder as a live exam portal.

# Plan a Cybersecurity Certification — Without Collecting Random Certificates

**Pain point:** learners can spend heavily on training and exams without knowing whether the credential matches their level or career goal.

**GHC approach:** learn foundations → practice skills → choose a certification → assess readiness → book the exam when prepared → continue building evidence.

## Choose by career direction

| Target role | Knowledge areas | Common certifications to research |
| --- | --- | --- |
| Entry-level IT / security | Networking, operating systems, general security | CompTIA Network+, Security+ |
| Ethical hacking / pentesting | Enumeration, web, systems, reporting | CEH, OSCP |
| Cloud security engineer | Cloud IAM, networking, logging, secure architecture | AWS security-focused certifications |
| Security architecture / leadership | Governance, risk, security design, operations | CISSP |
| Application security | HTTP, APIs, secure SDLC, threat modeling | Relevant vendor-neutral or specialist programs |

These are **examples for planning**, not eligibility endorsements or guarantees. Always check the exam provider's latest prerequisites, objectives, fees, policies and trademark guidance.

## 12-week adjustable preparation framework

| Stage | Weeks | Deliverable |
| --- | --- | --- |
| Baseline | 1–2 | Skills-gap checklist mapped to current exam objectives |
| Concepts | 3–5 | Notes and diagrams for weak domains |
| Practical application | 6–8 | Authorized lab or scenario reports |
| Review | 9–10 | Practice questions with explanations and error log |
| Readiness decision | 11–12 | Full syllabus review; decide whether exam booking is justified |

For advanced or experience-based certifications, significantly more preparation and verified work experience may be required. The schedule above is an example, not an exam-readiness guarantee.

## Before booking an exam

- Verify that the official exam objectives are current.
- Check eligibility and any work-experience or endorsement requirements.
- Estimate exam costs and any retake policy.
- Use **original or properly licensed** practice questions, never leaked exam dumps.
- Assess weaker domains and explain answers without memorizing shortcuts.
- Save funds for an exam only after making an informed readiness decision.

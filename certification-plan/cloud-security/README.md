# Cloud Security — AWS-Focused Career and Certification Roadmap

**Who this helps:** IT, cloud and security learners pursuing IAM, monitoring and secure architecture skills.

**Official certification information:** https://aws.amazon.com/certification/certified-security-specialty/

## What to learn

1. **Cloud shared responsibility and security architecture** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
2. **Identity, policies, credentials and least privilege** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
3. **Networking, segmentation and encryption** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
4. **Logging, detection and incident response** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
5. **Infrastructure as code and configuration assessment** — explain the concept, identify relevant risks, then apply it only within a safe training environment.

## Portfolio-focused practice

1. Diagram an isolated two-tier cloud architecture without deploying paid resources.
2. Inspect synthetic IAM permissions and document overprivilege.
3. Write a cloud logging and incident-response checklist.

**Important:** AWS exam identifiers and objectives change; confirm the latest AWS Certified Security – Specialty exam guide, requirements, costs and scheduling directly with AWS. Avoid unexpected cloud charges by using offline or free synthetic exercises first.

## Common learning approach

1. Check the provider's **current official objectives and eligibility** before buying training or an exam.
2. Build fundamentals with [GHC Foundation](https://foundation.gohackerscloud.com/) and [Academy](../../academy/README.md).
3. Practice only in local, synthetic or explicitly authorized lab environments; [GHC Labs](../../ghc-labs/README.md) may reduce setup burden where your membership includes them.
4. Record what you learned in a sanitized [project portfolio](../../guidance/portfolio-building/README.md).
5. Review mistakes and retest without using exam dumps or copyrighted question banks.

# CEH — Ethical Hacking Study Roadmap

**Who this helps:** Students moving from security fundamentals toward structured ethical-hacking knowledge.

**Official certification information:** https://www.eccouncil.org/train-certify/certified-ethical-hacker-ceh/

## What to learn

1. **Ethics, written authorization and scope** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
2. **Network discovery and enumeration in a sandbox** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
3. **System and web application security concepts** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
4. **Cloud, wireless, cryptography and reporting concepts** — explain the concept, identify relevant risks, then apply it only within a safe training environment.

## Portfolio-focused practice

1. Produce a fictitious rules-of-engagement document.
2. Inspect a locally hosted HTTP training application.
3. Write a sample vulnerability finding and remediation note.

## Example preparation progression

| Stage | Activity | Evidence |
| --- | --- | --- |
| Baseline | Map your current knowledge against today's official objectives | Skills-gap checklist |
| Fundamentals | Review networking, operating systems and security concepts | Annotated notes |
| Practical | Complete relevant authorized scenarios | Synthetic lab findings |
| Assessment | Use original questions and explain wrong answers | Review log |
| Readiness | Evaluate time, exam requirements and budget | Personal exam decision |

**Important:** CEH certification and CEH Practical are distinct credentials. Verify current authorized training, eligibility, exam versions, certification routes and costs directly with EC-Council.

## Common learning approach

1. Check the provider's **current official objectives and eligibility** before buying training or an exam.
2. Build fundamentals with [GHC Foundation](https://foundation.gohackerscloud.com/) and [Academy](../../academy/README.md).
3. Practice only in local, synthetic or explicitly authorized lab environments; [GHC Labs](../../ghc-labs/README.md) may reduce setup burden where your membership includes them.
4. Record what you learned in a sanitized [project portfolio](../../guidance/portfolio-building/README.md).
5. Review mistakes and retest without using exam dumps or copyrighted question banks.

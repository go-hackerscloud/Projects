# OSCP / OSCP+ — Practical Penetration Testing Roadmap

**Who this helps:** Learners who already understand Linux, networking, web security and basic scripting.

**Official certification information:** https://help.offsec.com/hc/en-us/articles/12483872278932-PEN-200-FAQ

## What to learn

1. **Scope, enumeration methodology and note-taking** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
2. **Linux and Windows attack-surface understanding** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
3. **Web and Active Directory security fundamentals** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
4. **Privilege-escalation reasoning in authorized exercises** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
5. **Evidence, technical reporting and retest** — explain the concept, identify relevant risks, then apply it only within a safe training environment.

## Portfolio-focused practice

1. Write a permission-safe enumeration checklist.
2. Document a deliberately vulnerable local application finding.
3. Produce a timed synthetic assessment report.

**Important:** OffSec uses OSCP/OSCP+ designations and PEN-200 training terminology. Verify the current exam, report rules, tool restrictions, subscription conditions and certification validity on OffSec's official pages. Do not publish exam spoilers.

## Common learning approach

1. Check the provider's **current official objectives and eligibility** before buying training or an exam.
2. Build fundamentals with [GHC Foundation](https://foundation.gohackerscloud.com/) and [Academy](../../academy/README.md).
3. Practice only in local, synthetic or explicitly authorized lab environments; [GHC Labs](../../ghc-labs/README.md) may reduce setup burden where your membership includes them.
4. Record what you learned in a sanitized [project portfolio](../../guidance/portfolio-building/README.md).
5. Review mistakes and retest without using exam dumps or copyrighted question banks.

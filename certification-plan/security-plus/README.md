# CompTIA Security+ — Core Security Study Roadmap

**Who this helps:** New cybersecurity learners with basic IT and networking knowledge.

**Official certification information:** https://www.comptia.org/en-us/certifications/security/

## What to learn

1. **General security principles and foundational terminology** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
2. **Threats, vulnerabilities and mitigations** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
3. **Security architecture, identity and access** — explain the concept, identify relevant risks, then apply it only within a safe training environment.
4. **Security operations, incident handling and governance** — explain the concept, identify relevant risks, then apply it only within a safe training environment.

## Portfolio-focused practice

1. Build a threat/control mapping table for a fictional company.
2. Review a synthetic access-control scenario.
3. Document triage steps for a synthetic suspicious log entry.

**Important:** CompTIA updates exam codes, content outlines and retirement schedules. Always use its current official objectives; do not assume a guide is aligned to a specific exam version.

## Common learning approach

1. Check the provider's **current official objectives and eligibility** before buying training or an exam.
2. Build fundamentals with [GHC Foundation](https://foundation.gohackerscloud.com/) and [Academy](../../academy/README.md).
3. Practice only in local, synthetic or explicitly authorized lab environments; [GHC Labs](../../ghc-labs/README.md) may reduce setup burden where your membership includes them.
4. Record what you learned in a sanitized [project portfolio](../../guidance/portfolio-building/README.md).
5. Review mistakes and retest without using exam dumps or copyrighted question banks.

# Community Projects

A home for **original, safe and reproducible** learner contributions.

## Project proposal template

- Project title and intended audience
- Learning objective and prerequisites
- Environment (local, synthetic, or explicitly authorized)
- Steps and expected observations
- Evidence and documentation requirements
- Cleanup or reset process
- Credits and license information for any assets

Start by opening an issue and reading [contribution guidelines](../../CONTRIBUTING.md).

No third-party copyrighted course materials, leaked exam questions, production credentials, or unauthorized scan reports.

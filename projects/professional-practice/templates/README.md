## Quality checklist

- [ ] Every material statement cites an evidence ID or is explicitly a hypothesis
- [ ] No real organization, system, account or person is impersonated
- [ ] No client data, tokens or credentials are attached
- [ ] Proposed fixes are not marked implemented
- [ ] Reports state that no live verification took place
- [ ] The portfolio does not claim professional customer experience

# Courses and certification learning paths

Find training options and certification-oriented learning resources through GoHackersCloud.

**Course catalog:** https://www.gohackerscloud.org/courses

## Explore by goal

| Learning goal | Examples of relevant study areas |
| --- | --- |
| Build a security foundation | Networking, Linux, security principles |
| Prepare for ethical hacking | Enumeration, web security, reporting |
| Develop penetration-testing skills | Web, API, infrastructure, Active Directory |
| Learn cloud security | AWS security, IAM, cloud monitoring |
| Build security leadership knowledge | Security governance, risk, architecture |

Specific course availability, enrollment eligibility, and pricing are shown on the official catalog; they may change.

## Learning model

**Concepts → guided projects → hands-on practice → assessment → portfolio evidence**

This public repository provides links, sample roadmaps and free material. It does not contain paid course content.

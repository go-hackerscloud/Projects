# Cybersecurity Resume Optimization

A strong security resume explains your **scope, actions and evidence**, not just tool names.

## Recommended structure

1. Name, location, contact links and portfolio
2. Targeted professional summary (2–3 short lines)
3. Relevant technical skills, grouped by area
4. Work experience with verified outcomes
5. Two or three selected projects with evidence links
6. Relevant education and genuinely earned certifications

## Example transformation

**Generic:** “Know Linux and cybersecurity tools.”

**Evidence-focused:** “Configured an isolated Linux test environment, reviewed SSH settings and documented hardening recommendations in a reproducible lab report.”

Use that example only if it reflects work you actually completed. Never invent employment, qualifications, vulnerabilities discovered, or numerical impact.

## Resume review checklist

- Match your skill keywords to a **real** role description without keyword stuffing.
- Use a readable single-column layout that exports cleanly to PDF.
- Show outcomes and artifacts when available.
- Include links that resolve and do not expose confidential data.
- Proofread and tailor the summary for each application.

# Cybersecurity Interview Preparation

Prepare to explain *why* you took an action, not only which command you ran.

## Interview practice structure

| Topic | Practice question |
| --- | --- |
| Networking | What changes between a DNS lookup and an HTTP request? |
| Linux | How would you safely investigate suspicious process activity? |
| Cloud | Explain least privilege in cloud IAM using an example. |
| Application security | How do you prioritize and report an authorized web security finding? |
| Communication | Describe a time you changed your approach after receiving new evidence. |

## Project walkthrough framework

**Context → objective → safe environment → methodology → observation → limitations → remediation → lesson learned.**

If you lack professional experience, discuss a clearly labeled personal or training project. Do not present lab findings as enterprise production incidents.

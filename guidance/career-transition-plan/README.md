# Career Transition Plan — From Learning to Evidence

**Pain point:** "I've finished courses, but I have no professional security experience."

A training lab can demonstrate a **skill**, but must never be presented as a customer engagement, a previous job or a professional certification.

## Choose a target role and collect evidence

| Role direction | Skills to learn | Safe public evidence |
| --- | --- | --- |
| SOC / Security analyst | Networking, event triage, incident workflow | Synthetic alert triage with timeline |
| Pentester | Authorized scoping, enumeration, validation, reporting | Isolated lab finding and retest |
| Cloud security engineer | IAM, network boundaries, logging, encryption | Architecture review and fictional access matrix |
| Application security | Web/API security, SDLC, threat modeling | Threat model of a sample application |
| GRC / Security architect | Risk, policy, architecture and controls | Fictional risk register and control recommendation |

## An achievable six-week portfolio sprint

| Week | Milestone | Output |
| --- | --- | --- |
| 1 | Choose one job family and review multiple genuine job descriptions | Target-role skills list |
| 2 | Learn missing fundamentals through Foundation | Notes and concept map |
| 3 | Complete one permitted project or lab | Sanitized technical evidence |
| 4 | Write and improve the project report | Clear README with findings and remediation |
| 5 | Practice explaining decisions; tailor resume and LinkedIn | Evidence-based profile |
| 6 | Revisit weaknesses, practice interviews and apply selectively | Updated portfolio and action log |

This is a suggested schedule, not a guarantee of hiring or readiness. Some career paths require longer preparation, professional experience, or credentials.

## Tell the truth about project experience

**Avoid:** "Performed enterprise penetration testing for a production client" when your experience is only a hosted training lab.

**Use:** "Completed an authorized web application assessment in an isolated training lab, documented observations and proposed remediation."

## Connecting to GHC's business-facing work

GoHackersCloud provides [Cybersecurity Services](https://gohackerscloud.com/cybersecurity-services).

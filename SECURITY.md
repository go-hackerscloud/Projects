# Security policy

This repository contains public learning resources and sample projects. It is **not** the source repository for GoHackersCloud production authentication, lab provisioning, or customer services.

## Reporting

Please do **not** publish exploitable production findings, credentials, access tokens, personal data, or security-sensitive details in public issues or pull requests.

Contact the maintainers privately through the [official contact page](https://gohackerscloud.com/contact-gohackerscloud) to request a confidential reporting channel. Do not perform testing on GoHackersCloud services without explicit authorization.

## Safe demonstrations

All security demonstrations must be limited to local, synthetic, or explicitly authorized lab environments. Never commit secrets or real customer data.

# Cybersecurity career roadmaps

Use these free orientation paths to identify the next skill to learn and demonstrate.

| Career direction | Foundations | Practical evidence |
| --- | --- | --- |
| Security analyst | Networking, Linux, logs, incident lifecycle | Write a sample alert triage note |
| Penetration tester | HTTP, networking, enumeration, web security | Write an authorized lab finding report |
| Cloud security engineer | IAM, networking, logging, shared responsibility | Document a cloud security review in a sandbox |
| Application security engineer | Web architecture, APIs, secure development | Create a threat model for a demo app |
| Security architect | Risk, identity, architecture, governance | Produce a security design review |

These are educational roadmaps, not guarantees of employment or certification.

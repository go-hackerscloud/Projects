# Learning Cybersecurity Without an Expensive Laptop

**Problem:** students are sometimes told they need a powerful laptop, multiple virtual machines, paid cloud accounts and a large tool collection before they can start.

**Better starting point:** understand the concepts, practice using lightweight tools, and move heavier exercises to a preconfigured browser-accessible lab if your enrollment provides access.

## What you need first

- A functioning laptop or desktop, or a compatible device with a modern browser
- A reasonably stable internet connection for hosted labs
- A text editor, notes app, and a place to save your learning evidence
- Consistent practice time

**Not required on day one:** a dedicated gaming laptop, multiple local Kali VMs, a paid AWS account, or a large hardware upgrade.

## Practical options

| Device / situation | Low-friction learning option | Limitations |
| --- | --- | --- |
| Older Windows/Linux/Mac laptop | Foundation articles, cloud diagrams, short local scripts | Some programs and VMs may be slow |
| Limited disk or RAM | Browser-based lab access where eligible | Network latency and membership requirements apply |
| Shared computer | Browser reading and sanitized notes | Sign out and avoid storing sensitive data |
| Unreliable internet | Download permitted text notes for offline revision | Browser lab sessions still need connectivity |
| No personal laptop | Use a permitted library/college computer for reading | Access, browser controls and lab policies may vary |

## Spend money only when the next learning objective needs it

1. Start with public [GHC Foundation](https://foundation.gohackerscloud.com/) learning.
2. Choose a career goal and establish a study schedule.
3. Try lightweight local exercises before installing multiple VMs.
4. Review the [GHC Labs](../../ghc-labs/README.md) experience and current access terms.
5. Only consider hardware upgrades after you can name the actual task and required specifications.

## Why GHC Labs can help

GHC promotes preconfigured browser-accessible environments such as Kali and deliberately vulnerable practice applications. Where available to your account, these move much of the setup burden to a hosted sandbox. They **do not eliminate** internet requirements or guarantee the experience will work on every phone, tablet or old browser.

## Checklist before a paid commitment

- Is the lab included in the plan I want?
- Is the tool/environment necessary for my current learning path?
- Can I access it from my browser and network?
- How long does a session last? Will work persist?
- Can I complete the same beginner objective with free tools first?

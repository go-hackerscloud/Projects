# GHC Foundation

Build a strong base before moving into tools, advanced security techniques, or certification preparation.

**Website:** https://foundation.gohackerscloud.com

## Core topics

| Area | Start by learning |
| --- | --- |
| Networking | IP addressing, DNS, HTTP, routing, TCP/IP |
| Linux | Shell navigation, permissions, processes, logs |
| Security basics | CIA triad, identity, authentication, risk |
| Web technologies | Requests, responses, sessions, APIs |
| Cloud fundamentals | Shared responsibility, IAM, networking |
| Defensive thinking | Logging, patching, baselines and evidence |

## How to use Foundation

Start with one topic, take notes, apply the concept in a local or authorized sandbox, then move to a related Academy lesson.

The Foundation website and its own [public source repository](https://github.com/go-hackerscloud/gohackerscloud-foundation) are separate from this Learning Hub. This folder is a curated entry point rather than a duplicate deployment.

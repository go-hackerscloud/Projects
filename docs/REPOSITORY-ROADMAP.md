# GoHackersCloud public repository roadmap

This is a proposed publication plan, not a statement that every repository exists.

| Phase | Proposed public repository | Scope |
| --- | --- | --- |
| 1 | gohackerscloud-learning-hub | Cross-product public entry point |
| 2 | gohackerscloud-labs | Public lab catalog and sample lessons |
| 3 | crack-oscp-with-ghc | Independent OSCP preparation resources |
| 3 | pentesting-with-ghc | Practical authorized pentesting guides |
| 4 | ethical-hacking-with-ghc | Beginner-to-advanced ethical hacking learning |
| 4 | cissp-with-ghc | CISSP domain concepts and original practice material |
| 5 | cloud-security-with-ghc | Cloud security mini-projects |
| 5 | gohackerscloud-test-engine | Assessment showcase and sample questions |

Keep private: authentication, provisioning, deployment secrets, paid lesson content, and licensed question banks.

## Rename readiness

After the Learning Hub pull request is approved and merged:
1. Rename `Projects` to `gohackerscloud-learning-hub` using GitHub repository settings.
2. Confirm GitHub redirects and update cloning/remotes, pinned repositories, documentation, and external links.
3. Review repository description, topics, website field and visual identity.
4. Check public visibility and ensure no sensitive assets were introduced.

The rename is an administrative change separate from this documentation PR.


## Current status — 20 November 2026

The public hub is now **`learn-with-ghc`**. The previous `Projects` repository's five outdated sample folders were retired and must not be linked as active exercises.

We prioritize student accessibility, public learning pathways, guided project evidence and industry-relevant explanations. Foundation Project 01 — Linux Security Fundamentals is the first completed original local exercise introduced by this documentation branch.

The specialized repositories listed above are **proposals**, not available projects. Continue keeping authentication, worker infrastructure, production lab provisioning and paid course materials private.

# GoHackersCloud community

Welcome, learners, instructors, and contributors.

## Ways to participate

- Propose a beginner-friendly learning resource
- Improve documentation and accessibility
- Contribute a reproducible project that runs safely in a lab
- Report broken links or unclear instructions
- Suggest a career-roadmap improvement

Read [CONTRIBUTING.md](../CONTRIBUTING.md) before proposing changes.

**Free community entry:** https://learn.gohackerscloud.com/

Do not post credentials, personal information, live exploit targets, paid course material, or unauthorized scan results.


## Our community mission

GoHackersCloud reports having trained **10,000+ learners worldwide**. This is a GoHackersCloud-reported reach milestone, not an independently audited outcome, job placement count or external certification total.

We aim to make practice-based learning more accessible to students who face expensive hardware, difficult lab setup and uncertainty about professional pathways. The community can support learning through shared explanations, original educational projects and responsible collaboration.

Start with [the student support hub](../student-support/README.md), [Foundation](../foundation/README.md), or [Career Guidance](../guidance/README.md). Share what you learned in your own words; do not post paid solutions or confidential evidence.

## Share learning and contribute

- [Student Stories](./student-stories/README.md) — submission guidelines for voluntary learning journeys and original project showcases. No individual testimonials are published until reviewed and consented.
- [Community Contributions](./contribute/README.md) — propose corrections, beginner projects and accessibility improvements.
- [Student Portfolio Toolkit](../student-portfolio/README.md) — create a clear, privacy-safe project report before sharing.

**Before publishing anyone's story:** read the [publication policy](./student-stories/PUBLICATION-POLICY.md). Public GitHub pull requests are **not** a suitable collection channel for private consent records, identity details or verification documents.


## Community Showcase v1

The [GHC Community Showcase](./showcase/README.md) provides a public home for **real, reviewed learner projects**, not invented testimonials. Students can follow the [submission guide](./showcase/SUBMIT-A-PROJECT.md) and use the [showcase template](./showcase/PROJECT-SHOWCASE-TEMPLATE.md) for original, sanitized work.

For an identifiable student success story, use the separate [Student Stories](./student-stories/README.md) publication process and submit private verification/consent only through an approved private channel.

# Contribute to Learn with GHC

Join the community by improving public educational resources and helping other learners understand practical cybersecurity concepts.

## Contribution paths

| Path | Suitable work | How to begin |
| --- | --- | --- |
| Documentation | Fix a confusing explanation, typo or broken link | Open an issue with a specific proposed correction |
| Beginner project | Original authorized/synthetic reproducible exercise | Review [Community Projects](../../projects/community-projects/README.md) |
| Student portfolio | Sanitized project report written by you | Use the [Portfolio Toolkit](../../student-portfolio/README.md) |
| Student learning story | Voluntary, verifiable journey or reflection | Follow the [Student Stories policy](../student-stories/PUBLICATION-POLICY.md) |
| Accessibility | Low-spec-device alternatives, captions, clear commands | Propose a small documentation PR |

## From idea to public PR

1. Search existing issues and files to avoid duplication.
2. Open a clearly scoped issue **without personal information**.
3. Work in your own branch or fork. Follow [CONTRIBUTING.md](../../CONTRIBUTING.md).
4. Include the learning objective, prerequisites, safe environment, steps, expected observations, limitations, cleanup and sources.
5. Check the Markdown links, safety boundaries and accessibility.
6. Request review. Approval is not automatic; maintainers may request corrections.

## Safety and intellectual property

Never contribute exam dumps, paid lesson copies, production credentials, customer evidence, sensitive student records or results from unapproved security testing. Only publish works you have rights to share, and do not presume an open-source license exists where none is published.

## Recognition and verification

A merged contribution may be linked as a **public contribution** if the author chooses public attribution. Merging a PR is not an external certification or proof of employment. Do not promise badges or certificates until an actual issuance policy and mechanism exists.

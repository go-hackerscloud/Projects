# GHC Community Showcase v1

**Learn. Build. Document. Share — with permission and evidence.**

This space is ready to feature **real, original public learning projects** contributed by the GoHackersCloud community. It highlights practical skills, ethical scope and accessible learning—whether a learner uses a modest laptop, a local Python exercise or an eligible hosted GHC Lab.

> **Current publication status: Awaiting first approved community project.** No contributor profiles, testimonials, placements or certification achievements have been invented or published.

A showcased project is **not** an endorsement that its author can assess production systems, a third-party certification, or a GHC employment/placement outcome.

## Submit a project (public, sanitized work only)

1. Read the [submission guide](./SUBMIT-A-PROJECT.md).
2. Confirm your project is original and limited to an owned, synthetic or explicitly authorized environment.
3. Prepare a clear README using the [project showcase template](./PROJECT-SHOWCASE-TEMPLATE.md).
4. Complete the [publication readiness checklist](./REVIEW-CHECKLIST.md).
5. Open a public **Community Project Proposal** issue using the [GitHub issue template](../../.github/ISSUE_TEMPLATE/community-project.yml). Only submit non-sensitive project summaries and links.
6. A maintainer will review the link, request corrections when necessary, and invite a separate public PR for the final approved entry.
7. If any story involves private identity, quotations, photographs or career outcomes, follow the [private consent process](../student-stories/PUBLICATION-POLICY.md) instead. **Do not put private evidence or consent in GitHub.**

**Submission does not guarantee a feature.** A maintainer must review the content and verify permissions before adding a showcase entry.

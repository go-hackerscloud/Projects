# GHC Student Portfolio & Instructor Toolkit

**Turn learning into evidence, without expensive software or invented professional experience.**

This collection provides downloadable **Markdown templates** and repeatable review criteria for students, instructors, and colleges. Open any template, choose **Raw → Save As** in GitHub (or use the direct Raw link), then fill in a local copy using any text editor or Obsidian. No subscription is needed to use these public template files.

## Student workflow

1. Choose an existing [Foundation exercise](../projects/foundation-projects/README.md), [certification practice](../projects/certification-practice/README.md), or [Professional Practice capstone](../projects/professional-practice/README.md).
2. Read the scope and ensure the environment is local, synthetic, or explicitly authorized.
3. Copy the [project README template](./templates/PROJECT-README-TEMPLATE.md) and fill out the objective, architecture, methodology and results.
4. Fill the [assessment report](./templates/SECURITY-ASSESSMENT-REPORT.md) only when the activity involves a security finding.
5. Check [project completion](./checklists/STUDENT-COMPLETION-CHECKLIST.md), sanitize evidence, and request feedback.
6. Use the [instructor rubric](./instructor/ASSESSMENT-RUBRIC.md) to understand how reports are evaluated.
7. Publish a truthful, clearly labeled public portfolio with no credentials or sensitive data.

## Privacy, honesty and commercial boundaries

- **Synthetic exercises** must be labeled as training, not production testing or customer delivery.
- Never share API keys, passwords, cookies, real user data, real customer findings, unauthorized targets or paid answer keys.
- Student-created portfolio work is not a professional certification, placement promise or GHC Cybersecurity Services engagement.
- GHC Academy lessons or hosted lab access may require enrollment; these public templates do not bypass access controls.
- Do not use instructor assessment results as proof of an external vendor certification.

## Example of a portfolio statement

> "I reviewed a synthetic application role matrix and offline IAM policy, documented least-privilege gaps, proposed remediation, and prepared a retest plan. No live systems were tested."

This accurately communicates skill and scope without claiming nonexistent work experience.
